# 待办事项

本文件是仓库待办的唯一落点。任何未完成功能、已知缺口、后续优化、协议演进和验收工作都必须登记在这里；`AGENTS.md` 只保留「编号 + 一句话 + 未获明确授权前不要开工」的指针，不展开细节。

## 记录规则

每条待办必须包含以下字段，缺一项都算没写清：

- 编号
- 状态（待做 / 进行中 / 已完成）
- 前因后果
- 功能作用
- 现状：涉及的文件、函数、表、接口，以及已核实的结论
- 缺口与最小设计：前置条件、改动与注入点、边界与取舍，并明确「本条目不做什么」
- 已完成
- 未完成
- 验收标准
- 影响范围
- 关联文档

完成项不要静默删除：先更新状态、已完成内容和验收结果，再归档。
